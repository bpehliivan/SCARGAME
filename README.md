# SCAR GAME

SCAR GAME, tarayıcıda ve Windows masaüstünde çalışan bir akrobasi sürüş oyunu ve ders projesidir.

**SCAR yazılım geliştirme:** Burak Pehlivan  
**Bu revizyon:** 24 Kasım 2026

SCAR sürümünde Sonsuz mod, araç garajı, S Point ekonomisi, pist temaları, kişiselleştirilebilir plaka, sürüş rehberi ve yerel kayıt aktarımı geliştirildi.

## Çalıştırma

- Bağımlılıkları yüklemek için `npm ci`.
- Tarayıcıda geliştirme için `npm run dev`.
- Tür denetimi için `npm run typecheck`.
- Web paketi için `npm run build`. Çıktı `dist/` klasöründedir.
- Windows masaüstünde yerel açılış için derlemeden sonra `npm run desktop`.

## Kaynak ve varlıklar

SCAR, önceden var olan Roadster projesini temel alır. Önceki proje adresi `roadster.sebayaki.com` olarak kayıtlıydı. Yazılım geliştirme kredisi SCAR sürümündeki katkıyı belirtir.

Kullanılan araç modelleri ve bağımlılıklar kendi kaynaklarına ve lisanslarına tabidir. Bu belge temel proje veya harici varlıklar için yeni bir lisans vermez.
